# 因果推断 · 方法选型与解读参考

本文件供需要解释「为什么用这个方法、假设是什么、如何解读」时加载。

## 1. 方法选型决策表

| 数据形态 | 可用方法 | 核心假设 | 输出 |
|---|---|---|---|
| 横截面 + 可观察混杂 | PSM / IPW | 可忽略性（无未观测混杂） | ATE / ATT |
| 横截面 + 未观测混杂 | 工具变量 IV | 工具变量有效性 + 相关性 | LATE |
| 横截面 + 分配阈值 | 断点回归 RDD | 断点附近局部随机 | 断点处效应 |
| 面板 + 处理组/时期 | 双重差分 DID | 平行趋势 | 平均处理效应 |
| 面板 + 个体固定 | 固定效应 FE | 时变混杂可忽略 | 组内效应 |

## 2. 各方法要点

### PSM（倾向得分匹配）
- **思路**：按「接受处理的概率」匹配处理组与对照组，构造可比样本。
- **关键**：匹配后协变量平衡（SMD < 0.1），处理组与对照组重叠度（common support）。
- **局限**：只能控制**可观察**混杂；样本少时匹配质量差。

### IPW（逆概率加权）
- **思路**：用倾向得分的倒数加权，构造伪随机化总体。
- **关键**：极端的倾向得分（接近 0/1）会放大方差，需截断（clip）。
- **局限**：同 PSM，依赖可忽略性。

### IV（工具变量）
- **思路**：找一个只通过 treatment 影响 outcome 的变量，剥离未观测混杂。
- **关键**：第一阶段 F 统计量 > 10（否则弱工具变量，偏误放大）。
- **局限**：好工具变量极难找且难验证；估计的是 LATE（局部效应，只对「被工具推动」的人群有效）。

### RDD（断点回归）
- **思路**：有明确分配阈值（如考试 60 分、年龄 18 岁），断点附近近似随机。
- **关键**：运行变量在断点处不能有操控（manipulation），带宽选择。
- **局限**：结论只对断点附近人群有效。

### DID（双重差分）
- **思路**：比较处理组和对照组在干预前后的变化差异，消去共同趋势。
- **关键**：**平行趋势假设**——若无干预，两组变化趋势应一致；需做平行趋势检验。
- **局限**：政策若与其他同期事件混淆，效应会被污染。

### FE（固定效应）
- **思路**：组内去均值，控制所有不随时间变化的个体异质性。
- **关键**：只能估计时变变量的效应；时不变变量的效应被吸收。
- **局限**：时变混杂若存在且未观测，仍可能偏误。

## 3. 因果发现算法

| 算法 | 类型 | 输出 | 特点 |
|---|---|---|---|
| PC | 基于条件独立 | CPDAG（部分无向） | 经典、常用，假设忠实性 |
| FCI | 基于条件独立 | PAG（允许潜在混杂） | 允许存在未观测共同原因 |
| GES | 基于得分 | CPDAG | 贪婪搜索，大样本一致 |
| LiNGAM | 基于非高斯 | DAG（全有向） | 线性非高斯数据可定方向 |

## 4. 解读要点与常见误区

1. **因果结论 = 估计 + 假设**：所有方法都依赖无法完全验证的假设。汇报时必须带限定语「在 XX 假设下成立」。
2. **混杂选择是关键**：遗漏混杂 → 遗漏变量偏误；控制中介变量 → 过度控制偏误；控制碰撞变量 → 碰撞偏倚（collider bias）。不要盲目把所有变量当混杂。
3. **ATE ≠ ATT ≠ LATE**：ATE 是全体平均效应，ATT 是处理组效应，LATE 是工具变量下的局部效应。三者含义不同，汇报时要说清。
4. **显著性 ≠ 因果性**：p 值小只说明统计上非零，不代表因果链条成立。
5. **平行趋势不能完全验证**：只能检验干预前的趋势是否平行，无法检验干预后反事实趋势。
6. **因果发现是探索工具**：数据驱动的图结构可能受样本量、分布、隐藏混杂影响，必须结合领域知识，只能作为候选假设。
7. **共线性与弱工具**：工具变量若与 treatment 弱相关（F<10），2SLS 偏误会放大，宁可不用。

## 5. 输出解读建议

向用户交付时说明：
1. **效应大小 + 置信区间**：点估计和不确定度。
2. **方向**：正效应还是负效应。
3. **假设检验结果**：DID 平行趋势、PSM 平衡表、IV 第一阶段 F 值。
4. **限定语**：结论在哪些假设下成立，哪些假设无法验证。
